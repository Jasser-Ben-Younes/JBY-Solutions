What is it?

The JBY G-Code Post-Processor is a lightweight software tool that sits between your CAM package and your CNC machine. It takes the raw toolpath data exported by your CAM software and translates it into clean, correctly formatted G-Code that your controller can execute reliably — without manual editing.

Whether you're running a 3-axis mill, a lathe, or a router, the post-processor handles safe start/end blocks, tool changes, feed and speed output, and coordinate mode setup automatically.

Features

  • ✓ Compatible with Fanuc, Haas, Siemens, and generic ISO G-Code dialects
  • ✓ Supports 3-axis, 4-axis, and 5-axis toolpaths
  • ✓ Automatic safe-start and program-end blocks
  • ✓ Tool change management with spindle stop/start logic
  • ✓ Feed rate and spindle speed output in metric or imperial
  • ✓ Configurable output formatting via simple config file
  • ✓ Command-line interface — easy to integrate into existing workflows
